# Legacy Kivy Mobile Client

This directory contains the original Kivy-based Android client and its legacy Buildozer configuration. It is preserved for existing users and historical reference.

**For new installations, use the recommended PySide6 client in [`mobile_pyside6/`](../mobile_pyside6/README.md)** and download the prebuilt APK from the [latest mobile release](https://github.com/ArvinNotDev/InputBridge-Gamepad2XInput/releases/tag/mobile-latest).

The Kivy implementation is no longer the recommended download. Its source is kept here so the project retains the previous implementation and its feature history.
